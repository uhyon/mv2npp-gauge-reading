# mv2npp 아날로그 계기 자동 판독 요구명세서

작성일 2026-11-10 · 작성자 김보성 · 배경과 계획은 [PROPOSAL.md](PROPOSAL.md)

## 1. 문서 개요

이 문서는 mv2npp 아날로그 계기 자동 판독 시스템이 2026-11-26 포트폴리오 릴리스 시점에 만족해야 할 요구사항과 수용 기준을 정의합니다. 요구사항은 기능(FR), 비기능(NFR), 데이터(DR), 평가(ER)로 나누고 번호를 붙였습니다.

**우선순위**: **필수** = 11/26 릴리스에 반드시 포함, **권장** = 포함을 목표로 하되 빠지면 한계로 명시, **선택** = 조건이 맞거나 시간이 남을 때.

**용어**

| 용어 | 뜻 |
| --- | --- |
| % FS | 풀스케일 대비 오차. \|예측값 − 정답\| ÷ (scale_max − scale_min) × 100 |
| 바늘 위치 비율 | 최소 눈금에서 바늘까지의 각도 ÷ 최소~최대 눈금 각도 (0–1) |
| 구간 적중률 | 예측값이 MeasureBench의 허용 구간 안에 들어간 비율 |
| RETAKE | 판독이 불확실해 값 대신 재촬영을 요청하는 출력 |
| 열화 | 저조도, 방사선 스펙클, 모션 블러 등 원전 현장 조건을 흉낸 인위적 화질 저하 |

**참조 문서**: [PROPOSAL.md](PROPOSAL.md), [README.md](../README.md), [DATASETS.md](DATASETS.md), [RELATED_WORK.md](RELATED_WORK.md).

## 2. 시스템 개요 및 제약 조건

시스템은 계기 사진 한 장을 입력받아 검출 → 정면 보정 → 키포인트 → 눈금 OCR → 값 계산·경보의 5단계를 거쳐 값, 단위, 경보 상태(LOW / HIGH / NORMAL / RETAKE)를 출력합니다. 모델은 자체 합성 생성기의 이미지로 학습하고, 웹 데모로 공개합니다.

**사용자와 사용 상황**: 순찰 로봇·드론의 카메라, 또는 운전원의 휴대폰으로 찍은 계기 사진. 포트폴리오 단계에서는 웹 데모에 이미지를 올리는 방식으로 제공합니다.

**제약 조건**

| ID | 제약 |
| --- | --- |
| C-01 | 포트폴리오 릴리스 기한은 2026-11-26이며, 1인이 주 약 45시간 작업한다. |
| C-02 | 실제 원전 계기 사진은 구할 수 없고, 계기를 직접 촬영할 수 없다. |
| C-03 | 학습 GPU는 Colab·Kaggle 무료 GPU로 한정한다. 하드웨어(로봇 등)는 없다. |
| C-04 | 클라우드 작업 환경에서는 데이터셋 다운로드가 막혀 있어, 다운로드·실행은 사용자 PC에서 한다. |
| C-05 | 데이터셋 라이선스(DR 절)를 지킨다. 저장소에는 데이터셋을 커밋하지 않는다. |
| C-06 | 1차 범위는 바늘 하나짜리 원형 아날로그 계기(압력계·온도계·차압계)다. |

## 3. 기능 요구사항 (FR)

기능 요구사항은 13개이며, 그중 RETAKE 판정(FR-09)의 임계값은 아직 정해지지 않았습니다. 수용 기준의 "미정"은 8장 미결 사항에서 정합니다.

| ID | 요구사항 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- |
| FR-01 | 합성 생성기는 설정 파일로 문자판(범위, 단위, 눈금 호, 주눈금 수, 글꼴)과 카메라(yaw, pitch, 크기)를 무작위화한 2D 계기 이미지를 만든다. | 필수 | `configs/synth_2d.yaml`로 640 px 이미지 20,000장이 생성된다. 같은 seed로 두 번 돌리면 같은 결과가 나온다. |
| FR-02 | 생성기는 이미지마다 계기 박스, 바늘 중심·끝, 최소·최대 눈금 키포인트, 범위, 단위, 실제 값을 자동 저장한다. | 필수 | 저장된 키포인트로 `geometry.py`가 계산한 값이 저장된 값과 일치하는지 테스트로 확인한다. |
| FR-03 | 생성기는 원전 현장 조건(저조도, 유리 반사, 모션 블러, 방사선 스펙클, 오염)을 설정된 확률로 적용한다. | 필수 | 적용된 조건이 이미지별 라벨에 기록되고, 조건별 비율이 설정 확률(0.3 / 0.3 / 0.2 / 0.2 / 0.2)과 맞는다. |
| FR-04 | 계기 검출: 사진에서 계기 위치를 찾아 잘라낸다. | 필수 | ER-04를 따른다. |
| FR-05 | 정면 보정: 비스듬한 문자판을 호모그래피로 정면화한다. | 필수 | yaw ±50°, pitch ±40° 합성 검증셋에서 보정 전후 판독 오차를 비교해 보고한다. |
| FR-06 | 키포인트: 바늘 중심·끝, 최소·최대 눈금을 찾고 점마다 신뢰도를 낸다. | 필수 | ER-03을 따른다. |
| FR-07 | 눈금 OCR: 눈금 숫자와 단위를 읽어 scale_min, scale_max, 단위를 정한다. | 필수 | MeterFL 274장에서 범위·단위 인식률을 따로 보고한다. 목표치는 미정. |
| FR-08 | 값 계산: 바늘 각도를 눈금 범위에 대입해 값을 구한다. | 필수 | `tests/test_geometry.py`가 통과한다. |
| FR-09 | RETAKE: 키포인트·OCR 신뢰도가 임계값보다 낮으면 값 대신 RETAKE를 출력한다. | 필수 | ER-06을 따른다. 임계값은 미정. |
| FR-10 | 경보: 계기별 정상 범위와 비교해 LOW / HIGH / NORMAL을 판정한다. | 필수 | 경계값 단위 테스트가 통과한다. 정상 범위를 받는 방법은 미정. |
| FR-11 | 출력: 값, 단위, 상태, 신뢰도, 키포인트를 그린 이미지를 반환한다. | 필수 | 데모와 평가 스크립트가 같은 출력 형식을 쓴다. |
| FR-12 | 웹 데모: Gradio 앱을 Hugging Face Spaces에 공개해 이미지 업로드로 판독한다. | 필수 | 공개 URL에서 예제 이미지 판독이 동작한다. 예제는 DR-06을 지킨다. |
| FR-13 | 열화 모듈: 저조도, 방사선 스펙클, 모션 블러(선택: 유리 반사)를 강도 1–3으로 실사 이미지에 적용한다. | 필수 | 강도별 파라미터가 ER-05 표와 같고, 고정 seed로 같은 결과가 나온다. |

## 4. 비기능 요구사항 (NFR)

비기능 요구사항 중 측정 환경이 정해지지 않은 것은 처리 시간(NFR-01)입니다.

| ID | 요구사항 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- |
| NFR-01 | 처리 시간: GPU 없이 CPU에서 이미지 1장을 전체 파이프라인으로 0.5초 이내에 처리한다. | 권장 | ONNX Runtime 추론으로 MeterFL 274장의 장당 중간값이 0.5초 이하. 측정 CPU를 결과에 명시한다. |
| NFR-02 | 재현성: 합성, 학습, 평가, 열화가 모두 고정 seed와 설정 파일로 재현된다. | 필수 | README의 명령으로 성능표를 다시 만들 수 있다. 실험은 Weights & Biases에 기록한다. |
| NFR-03 | 코드 품질: 단계별 모듈(`synth`, `detection`, `keypoints`, `reading`)로 나누고 단위 테스트를 둔다. | 필수 | `pytest`가 모두 통과한다. |
| NFR-04 | 배포: 모델을 ONNX로 내보내 경량 실행한다. | 권장 | 데모가 ONNX Runtime으로 동작한다. |
| NFR-05 | 문서화: README에 데모 GIF, 성능표, 파이프라인 구조도, 한계, 데이터셋 출처를 적는다. | 필수 | 11/26 시점 README에 다섯 항목이 모두 있다. |
| NFR-06 | 투명성: 실제 원전 계기 사진이 평가에 없음을 결과와 함께 명시한다. 측정하지 않은 목표는 결과로 적지 않는다. | 필수 | README와 docs/DATASETS.md에 한계 절이 있다. |
| NFR-07 | 라이선스: 코드는 MIT로 공개한다. | 필수 | LICENSE 파일이 있다(충족). |

## 5. 데이터 요구사항 (DR)

학습은 자체 합성 데이터로 하고, 공개 실사 데이터는 평가에만 씁니다. 데모에 쓸 수 있는 이미지는 자체 합성 렌더와 CC BY 4.0 Roboflow 이미지뿐입니다.

| ID | 요구사항 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- |
| DR-01 | 학습 데이터는 자체 합성 데이터를 주로 하고, Synanthropic(MIT)을 보조로 쓸 수 있다. 평가용 실사는 학습에 쓰지 않는다. | 필수 | 학습 설정에 평가셋 경로가 없다. |
| DR-02 | MeterFL: 판독 정답 274장(`data/readings/*.json`)을 주 평가셋으로 쓴다. VLM으로 범위가 확인된 것 중 30장을 손으로 검수한다. | 필수 | 검수 결과(일치/수정 건수)가 기록된다. |
| DR-03 | MeasureBench: `scripts/filter_measurebench.py`로 압력·온도 다이얼 145장(기압계 제외 142장)을 남기고, 점 답 45장에 범위와 최소 눈금 간격을 손으로 단다. | 필수 | 필터 결과가 145 / 142장이고, `--manual-labels` 적용 후 점 답 45장에 범위가 채워진다. |
| DR-04 | Roboflow v4tii: 증강 사본을 빼고 원본 326장(train 245 / valid 49 / test 32)을 쓴다. 640×640 늘이기는 계기 박스 비율로 보정한다. | 필수 | 중복 제거 후 326장이다. |
| DR-05 | Roboflow obaw9: 1,471장을 자체 분할해 검출 평가에 쓴다. | 필수 | 분할 목록을 저장소에 기록한다. 분할 비율은 미정. |
| DR-06 | 데모와 README 이미지는 자체 합성 렌더와 CC BY 4.0 Roboflow 이미지(출처 표기)만 쓴다. Cambridge(NC), MeterFL, MeasureBench 이미지는 쓰지 않는다. | 필수 | 데모의 모든 예제 이미지에 출처가 붙어 있다. |
| DR-07 | MeterFL·MeasureBench에서 파생한 데이터(잘라낸 이미지, 재라벨)를 공개하면 CC BY-SA 4.0으로 배포한다. | 필수 | 파생 데이터에 라이선스 파일이 있다. |
| DR-08 | 데이터셋은 저장소에 커밋하지 않고 `scripts/download_data.py`로 `data/raw/`에 받는다. 결과표에 사용한 모든 데이터셋을 인용한다. | 필수 | `data/`가 git에서 제외되어 있다. |
| DR-09 | Cambridge RealGauges는 저자가 작동하는 링크를 줄 때만 평가에 추가한다. | 선택 | 현재 링크 중단, 두 주소 모두 메일 반송(2026-11-10). |

## 6. 평가 요구사항 (ER)

합격 기준이 수치로 정해진 것은 ER-01(판독 오차)과 ER-04(검출)이고, 나머지는 보고 의무만 있고 목표치는 미정입니다. 모든 평가는 합성 데이터만으로 학습한 모델로 합니다.

| ID | 평가 | 데이터 | 지표 | 수용 기준 | 우선순위 |
| --- | --- | --- | --- | --- | --- |
| ER-01 | 판독 정확도 (주) | MeterFL 274장 | 평균 % FS, 2% FS 이내 비율 | 평균 2% FS 이하, 2% FS 이내 85% 이상. 잘라낸 이미지라 2–5단계만 측정한다고 명시 | 필수 |
| ER-02 | 판독 정확도 (보조) | MeasureBench 145장 | 구간 적중률, 손 라벨 부분집의 % FS | 기압계 포함/제외, 단위 없는 예측, 미라벨 점 답을 각각 따로 보고. 목표치 미정 | 필수 |
| ER-03 | 키포인트 | Roboflow v4tii 326장 | 박스 크기로 정규화한 키포인트 오차, 바늘 위치 비율 오차 | 두 지표를 보고하고 비스듬한 사진의 잔여 왜곡을 명시. 목표치 미정 | 필수 |
| ER-04 | 검출 | Roboflow obaw9 (자체 분할) | mAP@0.5 | 0.90 이상 | 필수 |
| ER-05 | 원전 조건 견고성 | ER-01–04 실사 + 열화 | 조건·강도별 지표와 깨끗한 이미지 대비 저하 | 저조도·스펙클·블러 × 강도 3단계 표를 보고. 허용 저하폭 미정 | 필수 |
| ER-06 | RETAKE 판정 | MeterFL 274장 (+ ER-05 열화본) | 재촬영 비율, 받아들인 판독의 % FS | 두 값을 함께 보고. 목표 비율 미정 | 권장 |
| ER-07 | 처리 시간 | MeterFL 274장 | CPU 장당 시간 | NFR-01을 따름 | 권장 |
| ER-08 | 학습 데이터 비교 | ER-01 | "합성만" 대 "합성 + 실사 소량" 대 "실사만" | 실사 학습 데이터 출처가 정해지면 수행 (논문용) | 선택 |
| ER-09 | Cambridge RealGauges | RealGauges | % FS, 각도 오차 | DR-09 조건이 맞을 때만 | 선택 |

**열화 강도 (ER-05, FR-13)**

| 조건 | 흉내는 것 | 강도 1 / 2 / 3 |
| --- | --- | --- |
| 저조도 | 어두운 기기실, 야간 순찰 | 감마 1.8 / 2.5 / 3.2 + 밝기에 맞춘 포아송 샷 노이즈 |
| 방사선 스펙클 | 방사선장에서 CMOS 센서의 픽셀 히트 | 핫 픽셀 0.05% / 0.2% / 0.5%, 히트의 10%는 짧은 줄 |
| 모션 블러 | 휴대·로봇 카메라 움직임 | 선형 커널 7 / 15 / 25 px, 방향 무작위 |
| 유리 반사 (선택) | 계기 유리 커버 반사 | 문자판의 5% / 15% / 25%를 덮는 타원형 반사 |

열화는 고정 seed로 한 번에 하나씩 적용해, 모든 모델이 같은 이미지를 보게 합니다.
