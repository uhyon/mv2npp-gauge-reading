# mv2npp 아날로그 계기 자동 판독 기획서

작성일 2026-11-10 · 작성자 김보성 · 요구사항은 [REQUIREMENTS.md](REQUIREMENTS.md)

## 1. 개요

원전 현장의 아날로그 계기(압력계·온도계) 사진 한 장에서 값을 자동으로 읽고, 정상 범위를 벗어나거나 판독이 불확실하면 알려주는 시스템을 2026-11-26까지 1인으로 개발합니다. 학습은 자체 합성 이미지로만 하고, 평가는 공개 실사 이미지와 원전 조건을 흉내 낸 합성 열화로 합니다.

| 항목 | 내용 |
| --- | --- |
| 과제명 | 합성 데이터 기반 원전 아날로그 계기 자동 판독 시스템 |
| 프로젝트 | mv2npp (Machine Vision to Nuclear Power Plant) |
| 수행 인원 | 1인 (김보성), 주 약 45시간 |
| 기간 | 2026-11-10 ~ 2026-11-26 (포트폴리오 완성), 이후 공모전·논문 |
| 저장소 | [github.com/uhyon/mv2npp-gauge-reading](https://github.com/uhyon/mv2npp-gauge-reading) (공개, 코드 MIT) |
| 관련 문서 | [요구명세서](REQUIREMENTS.md), [데이터셋](DATASETS.md), [관련 연구](RELATED_WORK.md) |

이 기획서는 2026-11-10까지 내린 결정을 정리한 것이며 새 범위를 추가하지 않습니다. 정해지지 않은 사항은 9장에 미결 사항으로 모았습니다.

## 2. 추진 배경 및 필요성

국내 가동 원전, 특히 구형 호기에는 운전원이 순찰하며 눈으로 읽고 손으로 기록하는 아날로그 계기가 많습니다. 이 과정에서 판독·기록 오류, 방사선 구역 체류에 따른 피폭, 순찰 인력 부담이 생깁니다.

- **디지털 전환 수요**: 순찰 로봇·드론 점검이 현장에 들어오려면 "카메라로 계기를 읽는" 기능이 먼저 필요합니다. KAERI도 같은 문제를 사족보행 로봇 순찰과 모터 구동 실계기 데이터 장치로 다루고 있습니다(KNS 2025 추계, ICCAS 2025, KNS 2026 춘계).
- **안전 요구와의 관계**: INL 보고서(INL/RPT-23-74920)는 안전 관련 원전 응용에서 비전 판독의 한계와 보수적 판단의 필요성을 다룹니다. 불확실할 때 숫자 대신 재촬영을 요청하는 설계가 이 요구에 맞습니다.
- **데이터 제약**: 원전 계기 실사진은 공개되지 않고, 이 프로젝트는 계기를 직접 촬영할 수도 없습니다. 따라서 정답이 자동으로 나오는 합성 데이터로 학습하는 접근이 현실적입니다.

## 3. 목표 및 범위

최종 목표는 2026-11-26까지 동작하는 웹 데모와 성능표가 있는 공개 저장소를 포트폴리오로 완성하는 것입니다. 공모전 출품과 논문은 그 결과를 바탕으로 이어갑니다.

**성능 목표** (선행연구 수준을 참고한 출발점)

| 지표 | 목표 | 측정 데이터 |
| --- | --- | --- |
| 계기 검출 mAP@0.5 | 0.90 이상 | Roboflow obaw9 |
| 판독 오차 (풀스케일 대비 %, 평균) | 2% 이하 | MeterFL 274장 |
| 오차 2% FS 이내 비율 | 85% 이상 | MeterFL 274장 |
| CPU 처리 시간 (이미지 1장, 전체 파이프라인) | 0.5초 이하 | 측정 환경 미정 |

**포함 범위**

- 바늘 하나짜리 원형 아날로그 계기: 압력계, 온도계, 차압계
- 합성 데이터 생성기(2D 우선), 5단계 판독 파이프라인, 경보(LOW / HIGH / NORMAL / RETAKE)
- 공개 실사 데이터 평가와 원전 조건 견고성 평가
- 웹 데모(Gradio, Hugging Face Spaces)와 저장소 문서

**제외 범위** (시간이 남으면 확장)

- 디지털 7세그먼트 표시기, 레벨 게이지, 밸브 개폐 표시
- 바늘이 여러 개인 계기, 혈압계(기본 제외)
- 3D(Blender) 합성: 2D 합성으로 먼저 시작하고 나중에 추가
- 실제 로봇·드론 하드웨어 연동, 원전 현장 실증

## 4. 선행 연구 및 차별점

합성 데이터로 계기를 읽는 연구는 이미 있지만, 원전 현장 조건에서의 성능 저하와 불확실할 때의 재촬영 판단을 함께 측정한 사례는 찾지 못했습니다. 전체 목록은 [RELATED_WORK.md](RELATED_WORK.md)에 있습니다.

| 연구 | 핵심 | 우리와의 차이 |
| --- | --- | --- |
| [Howells et al., CVPRW 2021](http://www.jjcvision.com/projects/gauge_reading.html) | Blender 50개 파라미터 합성, 합성만으로 학습, 바늘 오차 1° 미만 | 데이터 링크 중단, 원전 조건 미다룸 |
| [León-Alcázar et al., WACV 2024](https://arxiv.org/abs/2308.14583) | 3D 합성 + 2단계 CNN, 실사 4,813장 평가 | 코드·데이터 미공개 |
| [Reitsma et al., ICRA 2024](https://arxiv.org/abs/2404.08785) | 검출·분할·타원 적합·OCR, 상대 오차 약 2% | 공개 코드(MIT), 비교 기준선 후보 |
| KAERI 조용호 외 (KNS 2025 추계, ICCAS 2025, KNS 2026 춘계) | 모터 구동 실계기 데이터 장치, 로봇 순찰 | 같은 문제를 하드웨어로 풀고, 우리는 합성으로 풂 |
| MeasureBench (CVPR 2026), DialBench (2025) | VLM 계기 판독 벤치마크 | 보조 평가셋, VLM 비교 |

**차별점**

1. **합성 데이터만으로 학습**하고 공개 실사 데이터로 평가합니다.
2. **원전 조건 견고성**: 저조도, 방사선 스펙클, 모션 블러별 성능 저하를 수치로 보고합니다.
3. **RETAKE 판정**: 불확실하면 숫자 대신 재촬영을 요청하고, 재촬영 비율과 받아들인 판독의 정확도를 함께 보고합니다.
4. **CPU 0.5초/장**: GPU 없는 순찰 로봇에서도 동작하도록 합니다.

3번과 4번은 아직 설계 목표이며 측정 결과는 없습니다.

## 5. 접근 방법

사진 한 장을 다섯 단계로 처리해 값과 경보를 내놓습니다. 단계를 나눠 두면 어느 단계에서 오차가 생기는지 따로 분석할 수 있습니다.

1. **계기 검출**: YOLO 계열 검출기로 계기를 찾아 잘라냅니다.
2. **정면 보정**: 비스듬히 찍힌 타원형 문자판을 호모그래피로 폅니다.
3. **키포인트**: 바늘 중심·끝, 최소·최대 눈금을 히트맵 모델로 찾습니다.
4. **눈금 OCR**: 눈금 숫자와 단위를 읽어 범위를 알아냅니다(PaddleOCR 등 기존 모델).
5. **값 계산과 경보**: 바늘 각도를 눈금 범위에 대입해 값을 구하고 LOW / HIGH / NORMAL / RETAKE를 판정합니다. 각도→값 계산은 `src/gauge_reader/reading/geometry.py`에 구현되어 있습니다.

**합성 데이터 생성기 (2D 우선)**

- 문자판: 범위(0–10, 0–16, 0–25, 0–100, −1–1, 0–150), 단위(bar, kgf/cm², MPa, psi, °C, mmH2O), 눈금 호 180–270°, 주눈금 5–11개, 글꼴을 무작위로 바꿉니다.
- 카메라: yaw ±50°, pitch ±40°, 계기 크기 이미지의 25–90%.
- 원전 현장 조건: 저조도 30%, 유리 반사 30%, 모션 블러 20%, 방사선 스펙클 20%, 오염 20%의 확률로 적용합니다.
- 이미지마다 계기 박스, 키포인트, 실제 값을 자동 저장합니다. 설정은 640 px, 2만 장입니다(`configs/synth_2d.yaml`).

**기술 스택**: Python, PyTorch, Ultralytics, OpenCV, ONNX Runtime, Gradio, Weights & Biases. GPU는 Colab·Kaggle 무료 GPU를 씁니다. 데이터 다운로드와 실행은 사용자 PC에서 합니다.

## 6. 데이터 및 평가 계획

평가는 다섯 가지이며, 주 지표는 MeterFL 274장의 풀스케일 대비 오차(% FS)입니다. 직접 촬영이 불가능해서 공개 데이터만으로 구성했습니다.

| # | 평가 | 데이터 | 지표 |
| --- | --- | --- | --- |
| 1 (주) | 판독 정확도 | MeterFL 판독 정답 274장 (잘라낸 이미지, 검출 미포함) | % FS 오차, 2% FS 이내 비율. VLM으로 범위가 확인된 것 중 30장 손 검수 |
| 2 (보조) | 판독 정확도 | MeasureBench 압력·온도 다이얼 142장 (기압계 제외 139장) | 정답 구간 적중률. 범위를 손으로 단 부분집만 % FS. 점 답 45장 손 라벨 완료(바늘이 모호한 4장 제외, 단위 보완 1장 추가 후 42장) |
| 3 | 키포인트 | Roboflow v4tii 원본 326장 | 키포인트 오차(박스 크기 정규화), 바늘 위치 비율 오차 |
| 4 | 검출 | Roboflow obaw9 1,471장 (자체 분할) | mAP@0.5 |
| 5 | 원전 조건 견고성 | 1–4의 실사에 합성 열화 | 조건·강도별 지표 저하 |
| 선택 | Cambridge RealGauges | 저자 답장 시에만 (링크 중단, 메일 반송) | % FS, 각도 오차 |

견고성 평가는 저조도(감마 1.8 / 2.5 / 3.2 + 샷 노이즈), 방사선 스펙클(핫 픽셀 0.05% / 0.2% / 0.5%), 모션 블러(7 / 15 / 25 px)를 강도 3단계로, 고정 시드에 한 번에 하나씩 적용합니다. 유리 반사는 선택 항목입니다.

## 9. 위험 요소와 한계, 미결 사항

가장 큰 위험은 합성 이미지와 실제 사진의 차이(도메인 갭)입니다. 이 차이 자체가 논문 주제이기도 해서, 목표에 못 미쳐도 분석 결과는 남습니다.

| 위험 | 대응 |
| --- | --- |
| 합성으로 학습한 모델이 실사에서 성능이 떨어짐 | 도메인 랜덤화 강화, 사전학습 백본, 3단계 관문 미통과 시 2단계로 돌아가 합성 조건 보강 |
| 일정 압박 (단계당 4–5일) | 2D 합성으로 시작, 3D는 나중에 추가 |
| 평가 정답 품질 (MeterFL 범위가 대부분 VLM 확인, MeasureBench 범위 없음) | MeterFL 30장 손 검수, MeasureBench 점 답 45장 손 라벨 |
| "원전다움"이 약해 보일 수 있음 | 원전 조건 견고성 평가를 별도 지표로 보고, 순찰 로봇 시나리오를 데모에 포함 |

**명시할 한계**

- 평가에 실제 원전 계기 사진이 없습니다. 원전 현장 조건은 공개 산업용·웹 계기 이미지의 합성 열화로 근사합니다.
- 주 평가셋(MeterFL)은 잘라낸 이미지라 검출을 포함한 종단 성능은 obaw9에서 따로만 측정됩니다.
- RETAKE 판정과 CPU 0.5초는 아직 측정되지 않은 설계 목표입니다.

**미결 사항**

- [ ] "합성 + 실사 소량" 비교에 쓸 실사 미세조정 데이터의 출처 (직접 촬영이 불가능해져 계획의 "실사 100–300장"이 비어 있음)
- [ ] CPU 0.5초 측정 환경(어떤 CPU)
